# Offline event diagnostics

Run `python verification/diagnostics/audit_events.py` from the analysis folder, or use its absolute path. Requirements: Python 3, NumPy, SciPy. No PyTorch, checkpoint, image inference, environment step, or vehicle rollout is invoked.

Inputs:

- `../framework/log_excerpts.json.gz`: original field-selected P-B/P-V records.
- `../framework/source/curve_layer.py`: unchanged execution base.
- `../framework/source/v6_theory_lp.py`: unchanged sampled planning model.
- `visual_context.json.gz`: original visual event windows, peak summaries, and layer-log hashes, including truth-for-evaluation and endpoint fields.
- `../framework/lp_reference_decomposition.csv`: actual-time reference rows regenerated by the framework calculator.

Outputs:

- `pb_event_rows.csv`: 432 stopping branches, actual target margins, event-preceding checks.
- `pv_event_rows.csv`: all 27 S episodes, including those without override.
- `event_summary.json`: counts, reference ranges, full LP boundaries, target-update algebra checks.
- `../../reproduction/v6/theory_lp_complete.json` and `theory_lp_v16_complete.json`: full scans; original saved files remain unchanged.

P-B event flags and post-action memory belong to different causal instants. The checker uses the preceding state and excludes the image update received after the triggering action. Static substitutions hold the free-road cap, state, jerk, and backup fixed; they do not replay wrappers, future observations, or vehicle trajectories. A true-line interval is an offline reference, not an online input or safety guarantee.
