# v6 闭环实验：定理 1 的三个边界在实际感知–记忆–执行链路里的位置

日期：2026-09-14。脚本 `visual_dev/v5_timing_experiment.py`（`run6` / `summarize6`）、`visual_dev/v6_theory_lp.py`；结果 `runs/v5_timing/v6_formal_v22/`、`v6_formal_v16/`（每分支一个 JSON，含逐子步与逐决策记录）。

## 1. 目的

把论文定理 1 的结构（灯位置已知、灯色在 Δ 后可知；R 停车 / G 通行两种情境；延迟观察者在分辨前必须用同一准备；jerk 上限 j）搬到已部署的车辆模型与视觉链路上，检验三个边界（各情境可行 / 共同准备可行 / 无额外代价）是否按理论预测的方向和量级出现。v5 只覆盖第一个边界（停车是否来得及），且执行层不做共同准备；v6 补上后两个。

## 2. 理论预测：定理结构在已部署离散模型上的两阶段 LP

与执行层一致的离散动力学：DT = 0.5 s，a ∈ [−3.5, 2.6] m/s²，|Δa| ≤ j·DT，0 ≤ v ≤ v0，梯形积分。灯位置在 d0 = 200 m 处已知（t = 0），灯色在 Δ 后可知；机动窗口 T_m = 1.5·d0/v0（对应定理 T_m = 3Δ 与 d = 2v0Δ 的比例）；终端：R 停在线前（v = 0, x ≤ d0），G 过线并恢复 v0；终端加速度 0；目标：最小化期望损失时间 p·ΔT_R + (1−p)·ΔT_G，p = 0.5；延迟观察者前 K = Δ/DT 步动作对两情境相同（非预期约束）。这是“定理在已部署模型上的对应物”，不是定理三段斜坡族的 ρ 阈值；两者只在结构与方向上对应。

LP 里惩罚全部落在 G 支（R 支为 0），与式 (9) 的结构一致；无额外代价边界随 jerk 上限放宽而后移。LP 允许以应急级减速（−3.5 m/s²、jerk 上限内斜坡）停车，因此“共同准备可行”边界很靠后；执行层的“高速段平顺”判据更严（不允许应急回退），对应 LP 的“无额外代价”边界而不是可行边界。

**灯色延迟施加的位置与理由**：定理要求“灯位置已知、灯色未知”。在图像入口只隐藏灯色（灯箱可见、三灯全灭）需要检测器认出灭灯灯箱：原 v4 检测器对灭灯灯箱的逐帧检出只有 0–35%（灯色头还把灭灯判为绿）；两轮微调（`v6_finetune_off.py`，共 2000 步）把 off 判别提到 0.90，但 130 m 以外灭灯灯箱的逐帧检出仍只有 36–54%，闭环里隐藏期建不起轨迹，且亮灯教师 ROI 灯色精度由 0.996 降到 0.944。因此 v6 的灯色延迟施加在**感知输出处**：图像与检测照常（检测器、记忆规则、执行层全部保持原 v4r 权重与规则），只在指定位置之前把灯色概率置空，记忆以“位置已知、相位 unknown”建立轨迹（`VisionMemory.colorless_track`）。对常量命令的执行族实验，链路里没有 actor，这一延迟没有其它泄漏通道；对三个 S 策略，actor 的 Z 编码器仍看到带颜色的像素，这一组只作稳健性参照并如实标注。微调后的检测器在正常可见的 9 工况闭环探针上退化到 6/9 到达、1 次闯红灯（原检测器 9/9、0），故未采用，记录保留（`runs/pretrain_v4_off/`、`runs/probes/v6_probe_off_encoder.json`）。

**记录**：沿用 v5 的“2 s 命令 → 4 子步执行 → 状态与代价”接口；另记分辨前的最大减速（准备量）、灯色到达时的车速、四个时刻、余量 M_j。

## 4. 接口核对

- 同一分支两次运行逐子步一致（v5 已验，v6 沿用同一代码路径）。
- 灯色延迟期：记忆相位 unknown、位置已知（烟测 `v6_smoke_cm`：隐藏期 10–11 子步中 5–6 子步已建轨、相位全部 unknown、无红/绿）；cons 档准备减速 1.8–3.5 m/s²，min 档 0（v 保持 22.2）。
- jerk 三处参数统一（v5 已验）。

## 6. 结论与局限

列读法：目标采纳 d = 灯色到达记忆的设计距离；实际采纳 d = 记忆相位首次等于真值的距离（停 / 通两支）；“停车支 准备最大减速”= 灯色到达前的最大减速（准备量）；“通行支 Δ时间”= 该延迟条件的通行分支相对早知分支的时间差（同策略、同 jerk、同冻结状态的配对差）；LP 列 = 定理结构在已部署模型上的预测（共同准备是否可行 / G 支惩罚 / 最优准备减速）。

### 6.1 三个边界在链路里的位置（常量命令执行族）

| | 早知 | 延迟-最小准备（min） | 延迟-保守（cons） |
|---|---|---|---|
| 停车支高速段平顺 | 全部 | 采纳距离 ≥ 89 m（v0 22.2）/ ≥ 67 m（v0 16, jerk 2）平顺，再晚一步丢失 | 全部平顺（所有延迟、所有 jerk、两个速度） |
| 通行支时间代价 | 0 | 0，直到采纳距离 ≤ 67 m（jerk 2）/ ≤ 56 m（jerk 3、4）才出现 ≥0.5 s | 每个延迟都付：+0.5 s（150 m）→ +3.5 s（44 m）（v0 22.2, jerk 2） |
| 对应定理的区域 | Table I 第 4 行：早信息无额外价值 | 第 3 行：共同准备可行且无额外代价，直到边界；越过边界后要么失去平顺停车、要么付通行代价 | “为未发生的情境准备”的代价：可行但不免费 |

- **无额外代价边界**：LP 预测 89 / 89 / 78 m（jerk 2/3/4，v0 22.2）与 48 / 48 / 40 m（v0 16）；测得最小准备档丢失平顺的目标采纳距离 78 / 78 / 78 m（v0 22.2；上一档 89 m 全部平顺）与 56 / 44 / 44 m（v0 16）。两个速度下测量都落在 LP 边界的一个网格步（11 m / 8 m）之内，且随速度按 D_stop(v) 移动；jerk 依赖在 v0 16 上可分辨（jerk 2 比 jerk 3/4 早一档丢失），在 v0 22.2 上被 11 m 网格掩盖（LP 的差也只有一档）。
- **通行支惩罚的起点**：LP 首个非零惩罚出现在分辨距离 78 / 78 / 67 m；测得 ≥0.5 s 的惩罚起于目标采纳 67 / 56 / 56 m——方向一致（jerk 越宽松起点越晚），量级更大（执行层离散、0.5 s 感知量化、停车目标余量 0.15d+8）。
- **保守准备的代价**：cons 档在 150 m 就开始减速（1.8–2.2 m/s²），通行分支每个延迟都多花 0.5–3.5 s、8–24 Wh，停车分支始终平顺；LP 的最优准备在边界之前为 0——这正是定理里“延迟观察者若过度准备，则在通行分支付出不必要代价”的经验对应。
- **准备量**：min 档灯色到达前的减速为 0，直到采纳距离 ≤ 78 m 才出现 0.4–3.2 m/s²（由“停车仍可行”约束触发），与 LP 最优准备（0.57 / 1.50 / 2.29 / 2.61）同向递增。

### 6.2 冻结 S 策略

三个 S 策略在 min 档下自带约 1.9 m/s² 的减速（看到灯就减速，v4r 训练出的保守行为），因此种子 0、1 的停车分支在所有延迟下都平顺（v0 22.2），代价是通行分支与常量执行族相同的时间惩罚（+1.0 s @67 m 等）；种子 2 与常量执行族一样在 78 m 丢失平顺。v0 16 下三种子的丢失边界 56 / 32 / 56 m（jerk 2）。这些是“策略层的准备”叠加在执行层之上，不改变 6.1 的边界结论；因 actor 的 Z 看得到灯色像素，只作稳健性参照。

### 6.3 支持什么、不支持什么

支持：在同一冻结感知、记忆与执行层下，定理 1 的三个区域按预测的顺序与方向出现——早信息无代价；延迟信息在“无额外代价边界”之前可以零代价地保留两种响应（最小准备），越过边界后要么失去平顺停车（最小准备）、要么为未发生的情境付通行代价（保守准备）；边界随 jerk 上限与速度按备份制动距离移动，测量与已部署模型的 LP 预测差在一个感知网格步内。

不支持 / 局限：(1) LP 是定理结构在已部署模型上的对应物，不是定理三段斜坡族的 ρ 阈值；(2) 灯色延迟施加在感知输出处而非图像入口（原因见第 3 节），执行族实验无 actor，因此无泄漏通道，但 S 策略组的 actor 看得到灯色像素；(3) 采纳距离按 0.5 s 帧率量化（11 m / 8 m），jerk 依赖在 v0 22.2 上分辨不出；(4) 惩罚量级大于 LP，来自执行层离散与余量，不能把测得的通行支时间差读成最优信息损失；(5) 最小准备档由“停车仍可行”约束驱动，在边界前会自行轻微减速，不是理论上的零准备；(6) 停车分支的全程时间由等红灯主导（冻结后 50 s 转绿），只比较接近段与通行支。
